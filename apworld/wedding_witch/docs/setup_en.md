# Setup

Use the matching custom 0.3.0 BepInEx 5 Mono client and a new schema 2 seed. Keep upstream and additive prototype seeds with their original clients. Close the game and run Install.ps1 from the bundle. Press F8 in the main menu to enter host, port and slot.

For the supplied test seed use 127.0.0.1, port 38428, slot WitchTester. Both server collect_mode and release_mode are disabled. Saves remain separated by seed/team/slot. Returning to the main menu permits reconnecting after an outage.
